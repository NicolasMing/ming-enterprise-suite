# 明汇企业套件 UI

**Ming Enterprise Suite UI** 是明汇企业套件的 Vue3 管理后台。

- 前端仓库：<https://github.com/NicolasMing/ming-enterprise-suite-ui>
- 后端仓库：<https://github.com/NicolasMing/ming-enterprise-suite>
- 技术栈：Vue 3、TypeScript、Vite、Element Plus、pnpm

## 开发

```bash
pnpm install --frozen-lockfile
pnpm dev
```

项目保留并继续遵循上游 MIT License 与原作者署名。上游项目为 [yudao-ui-admin-vue3](https://github.com/yudaocode/yudao-ui-admin-vue3)，来源说明见 [docs/UPSTREAM_README.md](docs/UPSTREAM_README.md)。
